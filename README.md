# קורא חת"ת ורמב"ם יומי · chitas-reader

אתר/אפליקציה (PWA) ללימוד היומי: **חומש עם רש"י, תהילים, תניא, רמב"ם (3 פרקים / פרק אחד)** – בקריאה נוחה כמו על דף נייר.

**לאתר: https://dudidd-wq.github.io/chitas-reader/**

## מה יש
- שיעורי היום לפי לוח חב"ד, בחירת כל תאריך (חישוב במכשיר, ללא שרת); מצב חו"ל/ארץ ישראל.
- קריאה במסך מלא, עמודים (דפדוף) או גלילה, ערכות נייר/ספיה/כהה/לילה, גופנים מקומיים, גודל ורווח, טעמים ורש"י לבחירה, שמירת מיקום והתקדמות, מקלדת והחלקה, מסך דולק.
- טקסט מנוקד היכן שיש מקור פתוח מנוקד; טקסט לא מנוקד מסומן.
- ביאור קל (עד 4 מילים) מוויקימילון, עם מקור – בחומש ובתהילים.
- הקראה בקול הדפדפן (עברית): הדגשת פסוק, קריאה רצופה, מהירות, כפתורי אוזניות/מסך נעילה, מצב הטעמה, כלל לשם ה'.
- עובד אופליין; כל הנתונים נשמרים רק במכשיר; גיבוי/שחזור; בלי מעקב ובלי עוגיות.

## מבנה
`site/` – האתר (JS נקי, ללא build) · `tools/` – בניית נתונים, ביאורים, אימות, צילומים · `tests/` – בדיקות · `verification/` – תמונת מצב מ־Chabad.org ודוח אימות · `NOTES.md` – תכנון, כללים ופתוחים.

```
npm ci && npm test        # בדיקות לוח/טקסט/ביאורים/הקראה
npm run ui                # axe + גלישה + אופליין (דורש Chrome ושרת מקומי ב-8765)
```
