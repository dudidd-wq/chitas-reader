# Corresponding sources for optional GPL fonts

These font archives are separate works, not application code. Font binaries in `site/fonts/taamey-d` and `site/fonts/keter-yg` are byte-identical to their originals. Copyright notices and GPLv2 + font-embedding exception are retained beside them. No GPL font conversion or subsetting is performed. CSS synthetic bold does not modify font files.

- **Taamey D 1.2**: `TaameyD-1.2-sources.zip`, original complete corresponding-source archive (sources and build scripts), https://bdenckla.github.io/MAM-basics/taamey-d/downloads/snapshots/1.2-MAM-basics-1f1be97138d5/Taamey_D-sources.zip . Binary from matching snapshot `Taamey_D.zip`. Ben Denckla / Yoram Gnat / applicable URW notices preserved. https://bdenckla.github.io/MAM-basics/taamey-d/downloads/ .
- **Keter YG**: `KeterYG-original.zip`, complete original upstream archive with SFD sources, fonts, license, README and samples. https://culmus.sourceforge.io/taamim/KeterYG.zip . Yoram Gnat / Culmus. https://culmus.sourceforge.io/taamim/index.html . Only Medium is shipped to the site: native Bold has empty cantillation glyphs.

Equivalent public source access: these archives are committed in the same public repository as the binaries. The Sources page links directly to this directory and upstream. Archives are not PWA precached.
