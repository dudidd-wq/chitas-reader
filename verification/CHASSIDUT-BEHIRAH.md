**ההחלטה (1.0.54): הנוסח המנוקד של חסידות בהירה הוא מקור הניקוד לשיעור היומי בתורה אור ולקוטי תורה. אם המילה או הפסקה לא אומתה, מוצג נוסח קה״ת מספריא בלי ניקוד.**

> נוסח מנוקד: חסידות בהירה, על פי מהדורת קה״ת ה׳תשע״ה; באישור, לשימוש לא מסחרי בלבד – https://chassidutbehirah.com/

## רשות
לפי דיווח בעל האתר, אושר ע״י חסידות בהירה וקה״ת, לשימוש לא מסחרי בלבד.
- אין בריפו מסמך רישיון בכתב, ואין כאן טענה שקיים כזה.
- האתר לא מסחרי: אין בו פרסומות, תשלום או מכירה. הניקוד אינו ברישיון פתוח. מי שמעתיק את המאגר צריך לבקש רשות בעצמו, או להסיר את הניקוד: מריצים מחדש את `node tools/build-tolt.mjs` בלי שלב ה־apply.
- הייחוס מופיע בכל שיעור מנוקד (הערה בראש השיעור ושורת ״ניקוד״ בקרדיט), וגם בטבלת המקורות, באודות, ב־README, ב־`site/data/LICENSE-DATA.md` וב־`site/THIRD-PARTY-NOTICES.txt`.

## המקור
- 63 קובצי PDF (ייצוא מ־Word) של תורה אור, לקוטי תורה והוספות, בקישורי Google Drive ציבוריים מהאתר. המזהים והגדלים נמצאים ב־`tools/cb-niqqud/index.tsv`.
- ההורדה היא הורדה רגילה של הקבצים הציבוריים (`tools/cb-niqqud/fetch.sh`), בלי עקיפת הרשאות.
- **ה־PDF והקבצים שחולצו מהם אינם בריפו**, ואינם מוגשים מהאתר. באתר נמצאת רק התוצאה: סימני הניקוד שנוספו על מילות קה״ת.
- בפתח הקבצים נכתב שהדרושים הוגהו על פי מהדורת קה״ת ה׳תשע״ה.

## השיטה (`tools/cb-niqqud/`)
1. **חילוץ.** ה־ToUnicode בקבצים מעורבב, ולכן הטקסט נבנה לפי מזהה הגליף:
   - `gidmap.py` קורא את ה־cmap של הגופנים המוטמעים.
   - `bounds.py` קורא את תיבות הדיו.
   - `ligmap.py` מפרק ליגטורות GSUB של אות+סימנים. בגופן FbMazal, בקבצים 38–40 ו־63, רוב הניקוד נמצא בליגטורות. ליגטורה מתקבלת רק אם רכיביה הם אות עברית אחת וסימנים, ורק אם אות ה־ToUnicode תואמת לה.
   - `extract.py` מסדר טורים ושורות, ומשייך כל סימן לאות לפי הגאומטריה. חולם חסר משויך לפי הפינה השמאלית של האות. אותיות רחבות (FB20–FB29) מנורמלות.
2. **יישור.** `align.py` מיישר את מילות קה״ת (ספריא) של כל שיעור מול טקסט הספר המתאים. היישור הוא גלובלי, בגושים, עם יישור שני למקטעים שזזו (״מאמרים מוסגרים״, הוספות).
3. **קבלה** (`apply.py`). מילה מקבלת ניקוד רק אם **אותיותיה, בלי הניקוד, זהות בדיוק למילת קה״ת**. גם אז היא נדחית אם:
   - יש שתי תנועות על אות;
   - יש ש בלי נקודה (חוץ מש אחרי חולם, כמו מֹשֶׁה);
   - יש נקודת שי״ן על אות שאינה ש;
   - יש דגש באהח״ע״ר או בה״א שאינה בסוף מילה;
   - יש סימן על םןףץ, או סימן לא חוקי על ך;
   - אות באמצע מילה מנוקדת חסרה תנועה (חוץ מאהו״י ומאות שלפני וּ/וֹ);
   - המילה אינה מנוקדת ב־PDF.
   **ראשי תיבות וקיצורים (׳ ״) נשארים כמו בקה״ת.**
4. **פסקה** מסומנת `nq` רק אם לפחות 85% ממילותיה (בלי ראשי תיבות) אומתו. אחרת היא נשארת כולה כמו בקה״ת, בלי ניקוד. בפסקה מנוקדת, מילה שלא אומתה מוצגת כמו בקה״ת.
   כל פסקת `nq` נושאת `h`, שהוא sha1 של האותיות. `tests/tolt-niqqud.test.mjs` מוודא שהאותיות זהות לקה״ת, ושאין ניקוד בפסקה שאינה `nq` ובראשי תיבות. הוא בודק גם שאין מילים ״בלתי אפשריות״ שאותן היה מתקן `niqqud.js`, ושאין סימנים על אותיות סופיות. בנוסף נבדקים ייחוס, שם ה׳ בתצוגה ובהקראה, ושאין קובצי PDF ב־site/.
5. השוואת העיצורים של כל 8,148 הפסקאות מול נוסח קה״ת ב־HEAD, לפני השילוב: כולן זהות. אין אף תיקון מכני, ואין אף מילה בלתי אפשרית.

## שם ה׳, אותיות סופיות, גרש וגרשיים
- **תצוגה:** ״ה׳״, ״הוי׳״ ו״אלקים״ של קה״ת לא משתנים. הם קיצורים ואינם מנוקדים, ו־fullName/abbrName נוגעים רק ביי וביהוה. שם מנוקד כמו ״אֱלֹקִים״ מוצג כפי שהוא ב־CB.
- **הקראה (TTS):** בהגדרת ״השם״: ה׳ ← הַשֵּׁם, ואֱלֹהֶיךָ ← אֱלֹקֶיךָ. בהגדרת ״אדנ־י״: ה׳ ← אֲדֹנָי. ״אלקים״ ו״אֱלֹקִים״ נקראים ככתבם בשתי ההגדרות, כמו בנוסח הלא מנוקד. הבדיקות נמצאות ב־`tests/tolt-niqqud.test.mjs`.
- אין סימנים על םןףץ, ועל ך מותרים רק שווא, קמץ ודגש. גרש וגרשיים נשמרים כמו בקה״ת. אין סימן כפול על אות.
- סגנון CB שנשאר: דגש חזק אחרי מַה (״מַה שֶּׁהוּא״), וו כפולה (כַּוָּונָה), י כפולה. אלה סגנון ולא שגיאה, והאותיות זהות לקה״ת.

## מגבלות
- איכות הניקוד עצמו (דקדוק, קמץ קטן וכו׳) לא נבדקה מול מקור מנוקד שני. נבדקו רק התאמת האותיות והכללים המכניים שלמעלה.
- טעות ניקוד במקור, שאותיותיה תקינות ושלא נתפסה בכללים, תוצג.
- תיקונים אפשר לשלוח למערכת חסידות בהירה (כתובת התיקונים מופיעה בקבצים).

## הרצה מחדש
```sh
CB_DIR=/tmp/cbh sh tools/cb-niqqud/fetch.sh
cd /tmp/cbh && python <repo>/tools/cb-niqqud/gidmap.py && python <repo>/tools/cb-niqqud/bounds.py && python <repo>/tools/cb-niqqud/ligmap.py
mkdir -p work && for f in pdf/*.pdf; do python <repo>/tools/cb-niqqud/run_extract.py $f work/$(basename $f .pdf).json; done
cd <repo> && node tools/build-tolt.mjs && CB_WORK=/tmp/cbh/work python tools/cb-niqqud/apply.py && npm run data-version
python tools/cb-niqqud/report.py bereshit:1 noach:5 …   # טבלת הדגימה
```
(Python 3 עם pymupdf ו־fontTools.)
