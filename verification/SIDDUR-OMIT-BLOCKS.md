# Siddur omit blocks (1.0.68 re-audit)

**Rule (1.0.68):** `.sid-omit` only for a block that is plainly *dropped* on some days with nothing said in its place. Not omit-styled:
1. Alternatives / choices (the note says “say X instead”, במקומם/במקומן, substitute) – e.g. על נהרות בבל ↔ שיר המעלות.
2. Anything inside Birkat haMazon (brachot/4), an always-available prayer – its day variants are never omit-styled.
3. Verse- or line-level omissions inside a paragraph (shaded verse, ‘the following line’) – styling the whole paragraph is wrong.
4. Labels name the real condition (תחנון / שני וחמישי / Shabbat-YT) – a no-Tachanun or Mon/Thu variant is never labelled as a Shabbat/YT omission.
